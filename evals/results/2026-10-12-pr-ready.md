# pr ready decision samples, 2026-10-12

Two scenarios changed when `pr ready` replaced the hand-chained ready submission in submit-pr and express-issue. Each ran on Claude Sonnet once against the old text with the new criteria and twice against the changed text. The changed-text samples all passed. The old text failed the resume scenario and was partial on the transition scenario, so the criteria discriminate. The author graded the answers; independent review of the grades remains separate.

The [returned answers](2026-10-12-pr-ready-answers.txt) preserve the output used for grading. The source is the [issue #1054 delivery record](../../docs/research/trials/2026-10-12-issue-1054-qwen-delivery.md), where the ready submission took the worker twelve turns for four deterministic writes.

## Source and method

The changed source commit is `41d635601b71e9f334eb3d785fd7a58115e96017` on branch `pr-ready-cli`. The baseline commit is `a3ab747` on the local scratch branch `baseline-pr-ready`, which holds the skill text of main at `6cc6f46` plus the two updated scenario files. It is not for merge.

Runs used the Claude Code runner `2.1.296` with the controls that the [coordinator preparation report](2026-10-11-coordinator-preparation.md) records: restricted read-only file tools confined to the source snapshot, no command, web, MCP, or agent tools, and a minimal environment without identity or GitHub variables. The selected model was `claude-sonnet-5-5`, and every run reported that runtime model. The author of the change is Claude Fable 5.1. Runs took 8 to 12 seconds.

Both new-text resume answers read the PR, confirmed the head, ran `verify-commit --pr-head`, then named `pr ready` with the body file, `--expect-head c392966`, and the board target, and said to stop and report if it refused. One noted that it had not read `cli.md` and took the flag names from the task text.

The old-text transition answer resumed the worker and ran `gh pr ready` as a separate command with read-backs; it reached the decision without the single command, so it is partial. Both new-text transition answers resumed the worker, had it inspect the diff and rewrite the description, then run `pr ready` with the reviewed head and board target, and kept Copilot unrequested.

## Limits

One old-text sample per scenario. The samples establish that Sonnet reads the new sentences and names the command; they do not establish that a worker runs it correctly, which the next real delivery on a local model will show. The grades are the author's.
